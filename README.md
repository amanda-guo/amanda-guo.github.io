# Amanda Guo's Personal Website

This is my personal portfolio: a place to share how I bring product, design, and engineering together to build useful, AI-driven experiences.

Explore selected work across design, software, and AI + product; follow the story behind my career; and find ways to connect. The site also includes a theme toggle and links to projects and writing.

## Run locally

The project uses Node.js 22 and npm.

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite in your terminal.

To create and preview a production build:

```bash
npm run build
npm run preview
```
